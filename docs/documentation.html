Documentation v1.0.0

SolarPro Global is a complete, production-ready website template for solar PV installation businesses.

6 fully built HTML pages, an interactive savings calculator with real irradiance data for 10 countries, a filterable portfolio with lightbox, dark/light mode, currency switcher, and zero build-step dependency. Open a file in your browser and it works.

Quick Start

No installation, no terminal, no Node.js. Just open a file.

  1. Unzip the downloaded SolarPro-Global-v1.zip to any folder on your computer.
  2. Open index.html in Chrome, Firefox, Safari, or Edge.
  3. All 6 pages are linked internally and work on the file:// protocol.
  4. Edit the HTML files in any text editor (VS Code recommended) to customise content.
  5. When ready to go live, upload the entire folder to your hosting provider or deploy via Netlify / Vercel (see Deployment).

Internet required for first load: Tailwind CSS and AOS are loaded from CDN. The template requires an internet connection to render correctly. For fully offline use, download and self-host these libraries locally — instructions in the Tech Stack section.

Branding & Colors

Company Name / Logo

The logo text appears in the <nav> of every page. Search and replace SolarPro and Global with your company name across all 6 HTML files. To use an actual logo image instead of the SVG sun icon, replace the icon <div> with an <img> tag:

<!-- Replace the SVG icon wrapper with: -->
<img src="../assets/images/logo.svg"
     alt="Your Company Logo"
     width="32" height="32"
     style="border-radius:8px;" />

Color Scheme

All colors are defined as CSS custom properties in css/custom.css. Change these three values and every component updates automatically:

:root {
  --primary:   #f97316;  /* orange — main brand color */
  --secondary: #1e3a5f;  /* navy blue */
  --accent:    #eab308;  /* yellow */
}

Tip: Use a tool like coolors.co or uicolors.app to generate a harmonious brand palette. Keep the --primary value at 600-700 weight for contrast on white backgrounds.

Typography

The template uses the system font stack for zero-latency rendering. To add a custom font, add a Google Fonts <link> in the <head> of every HTML file and add the font-family to body in custom.css:

<!-- In <head> of each HTML file -->
<link rel="preconnect" href="https://fonts.googleapis.com" />
<link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;600;700;900&display=swap"
      rel="stylesheet" />

/* In css/custom.css — add to body selector */
body { font-family: 'Inter', system-ui, sans-serif; }

Content & Text

All content is written directly in the HTML files — no CMS required. Open any page in your text editor, find the relevant section, and edit the text. Every section has an HTML comment label (e.g., <!-- COMPANY STORY -->) to help you locate sections quickly.

  • Company name and tagline (hero sections of every page)
  • Founder/team names and bios (pages/about.html — Team section)
  • Company founding year and statistics (About page stats bar)
  • Service descriptions (pages/services.html)
  • Portfolio project details — see the Portfolio section

Footer copyright year: The footer on all 6 pages reads © 2026 SolarPro Global. Update this to your current year and company name. Search all files for 2025 SolarPro Global to find all instances.

Calculator Data

The solar savings calculator lives in js/calculator.js. All country-specific data is defined at the top of the file in the COUNTRY_DATA object. Open the file in any text editor to update tariffs as electricity rates change.

// js/calculator.js — update tariff rates here
const COUNTRY_DATA = {
  nigeria: {
    psh: 5.5,          // Peak Sun Hours — do not change unless you have updated data
    tariff: 68,        // ← Update this: NGN per kWh (2024 rate)
    currencyCode: 'NGN',
    currencySymbol: '₦',
    usdRate: 0.00063,   // ← Update this: 1 NGN in USD
    tariffInUSD: 0.043  // ← Update this: tariff converted to USD
  },
  usa: { psh: 5.0, tariff: 0.13, ... },
  // ... 8 more countries
};

Adding a New Country

Copy any existing country block, give it a unique key, and fill in the data:

australia: {
  psh: 5.6,             // From NASA POWER for central Australia
  tariff: 0.28,          // AUD per kWh
  currencyCode: 'AUD',
  currencySymbol: 'A$',
  usdRate: 0.65,         // 1 AUD in USD
  tariffInUSD: 0.182     // 0.28 × 0.65
},

Then add a matching <option> to the country select in pages/calculator.html:

<option value="australia">Australia (5.6 PSH)</option>

PSH data source: Use NASA POWER Data Access Viewer to look up annual average horizontal irradiance for any location. Divide the annual GHI (kWh/m²/year) by 365 to get the daily PSH value.

WhatsApp Link Format

WhatsApp deep links use this format:

https://wa.me/COUNTRYCODEPHONENUMBER?text=URL_ENCODED_MESSAGE

Examples:
https://wa.me/447700900000          ← UK number, no pre-fill
https://wa.me/12125551234           ← US number, no pre-fill
https://wa.me/447700900000?text=Hello%20there  ← with pre-filled message

Use urlencoder.org to URL-encode your custom pre-fill message text.

Google Maps Embed

The map placeholder in pages/contact.html shows instructions for embedding a Google Map. To add your real map:

  1. Go to maps.google.com and search for your address.
  2. Click Share → Embed a map → Copy the iframe HTML.
  3. In contact.html, find the <div class="map-placeholder"> element.
  4. Replace the entire <div class="map-placeholder">...</div> with the copied <iframe>.
  5. Add style="border:0;border-radius:0.75rem;width:100%;" and loading="lazy" to the iframe for consistent styling.
<!-- Replace the map-placeholder div with: -->
<iframe
  src="https://www.google.com/maps/embed?pb=..."
  width="100%"
  height="380"
  style="border:0;border-radius:0.75rem;"
  allowfullscreen
  loading="lazy"
  referrerpolicy="no-referrer-when-downgrade"
  title="Office location map">
</iframe>

Deploy to Netlify (Recommended)

Netlify offers the simplest one-step deployment with a free tier that covers all static websites.

Option A — Drag and Drop (30 seconds)

  1. Go to app.netlify.com/drop
  2. Drag and drop your SolarPro-Global-v1 folder onto the page.
  3. Your site goes live immediately at a random .netlify.app URL.
  4. Connect a custom domain in Site Settings → Domain Management.

Option B — Connect GitHub (Recommended for ongoing updates)

  1. Push the template folder to a GitHub repository.
  2. In Netlify: New Site → Import from Git → Select your repo.
  3. Build command: leave blank. Publish directory: leave blank (serves from root).
  4. Click Deploy. Every git push to main will auto-deploy.

Free custom domain: Netlify provides free HTTPS (Let's Encrypt SSL) for any custom domain connected to your site. No certificate purchase needed.

Deploy to Vercel

  1. Push the template to a GitHub (or GitLab) repository.
  2. Go to vercel.com/new and import your repository.
  3. Framework Preset: select Other.
  4. Build command: leave blank. Output directory: leave blank.
  5. Click Deploy. Your site is live at a .vercel.app URL.

Connect a custom domain in the project's Domains settings page.

Deploy to GitHub Pages (Free)

  1. Push the template folder to a public GitHub repository.
  2. In the repository: Settings → Pages → Source → Branch: main, folder: / (root).
  3. Click Save. Your site will be live at https://[username].github.io/[repo-name]/.

Path note: On GitHub Pages with a repo-name subdirectory (not a user/org site), internal links still work because all paths are relative. However, canonical URLs in the <head> will need updating to match the /repo-name/ base path.

Upload to cPanel / Web Hosting

  1. Log into your hosting provider's cPanel.
  2. Open File Manager and navigate to public_html (or www).
  3. Upload the entire SolarPro-Global-v1 folder, or upload a ZIP and extract it there.
  4. If deploying to the root domain, move all files from the extracted folder into public_html directly (so index.html is at public_html/index.html).
  5. Visit your domain — the site should be live.

For subdomains, upload to the subdomain's document root folder instead of public_html.

Self-Hosting CDN Libraries (Offline Mode)

To remove CDN dependency, download the libraries and reference them locally:

# 1. Download Tailwind standalone CLI and generate a CSS file:
npx tailwindcss -i ./css/custom.css -o ./css/tailwind.css --content "./**/*.html"

# 2. Replace the CDN tag in every HTML file with:
<link rel="stylesheet" href="../css/tailwind.css" />

# 3. Download AOS:
# - https://unpkg.com/aos@2.3.4/dist/aos.css  → save as css/aos.css
# - https://unpkg.com/aos@2.3.4/dist/aos.js   → save as js/aos.js
# Update references in all HTML files accordingly.

FAQ

Does this template require a backend or server?

No. This is a fully static HTML/CSS/JS template. It requires no server, no database, and no Node.js. It works directly in any browser and can be hosted on any static file host (Netlify, Vercel, GitHub Pages, cPanel, Amazon S3, etc.).

Does the contact form send real emails?

The form performs client-side validation and shows a success message on submission. It does not send emails — it is a frontend-only template. To receive real form submissions, connect the form to a backend service. Recommended options: Formspree (free tier available), Netlify Forms (if hosting on Netlify), or Web3Forms (no backend required).

Can I use this template for a client project?

Yes, the Single Use License permits use on one client project. If you are an agency or freelancer building sites for multiple clients, purchase a separate license for each.

How do I update the dark mode colors?

Dark mode colors are in the html.dark block in css/custom.css:

html.dark {
  --bg:      #0f172a;   /* deep navy page background */
  --bg-alt:  #1e293b;   /* section alternating background */
  --card-bg: #1e293b;   /* card background */
  --text:    #f1f5f9;   /* primary text */
  --text-muted: #94a3b8; /* secondary text */
  --border:  #334155;   /* card/input borders */
}

Can I add more pages?

Yes. Copy any existing page file as a starting point. The navbar, footer, dark mode script, and JS includes are identical across all pages — just copy and update the class="nav-link active" on the appropriate nav link and update the page title and meta description.
